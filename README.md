# Homebrew tap

[Homebrew](https://brew.sh) formulae by msetkowski.

## contact-sheet

[contact-sheet](https://github.com/msetkowski/contact-sheet) creates print-ready contact sheets (JPEG or PDF/X-4) from RAW, DNG, TIFF and JPEG photos.

```
brew install msetkowski/tap/contact-sheet
```

Or tap once and then use the short name:

```
brew tap msetkowski/tap
brew install contact-sheet
```

Works on macOS (Apple silicon and Intel) and Linux (x86_64 and ARM64); Homebrew installs the prebuilt binary from the GitHub release, so nothing is compiled. Update with `brew upgrade contact-sheet`.

The formula is generated by [`scripts/homebrew-formula.rb`](https://github.com/msetkowski/contact-sheet/blob/master/scripts/homebrew-formula.rb) and updated automatically by the contact-sheet release workflow – please report problems in the [contact-sheet repository](https://github.com/msetkowski/contact-sheet/issues).
